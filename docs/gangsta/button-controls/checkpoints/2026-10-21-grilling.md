# Grilling Conclusions

**Idea Verdict:** CHALLENGE — valid objective, refined by the Don's answers.

**Termination:** Single-pass complete. No unresolved CRITICAL objections.

## Key Decisions

1. **Retire the "resume from where it left off" wording.** D41 pauses/resumes the *run*, not a
   maneuver. No maneuver state survives a pause: a green-marker settle, junction pivot, or any
   future special process is fully dropped; resume always returns to plain line-following, and
   the process re-triggers from scratch if its condition is still present. No `Machine`,
   `ResumeTarget`, or turn-remainder arithmetic exists.
2. **D41:** hold 500 ms in Idle to start; a press pauses instantly; a press resumes instantly.
   `StartHeld` is inert outside Idle, so a start cannot instantly resume itself.
3. **D43:** 3 s hold calibrates only from Idle, AwaitingCalibration, or Paused. Inert while
   driving (a mid-run hold does nothing; D41 is the stop). 3 s hold from Paused abandons the run
   and returns to Idle.
4. **Refuse to start without a valid calibration.** Missing/corrupt blob → `AwaitingCalibration`,
   repeating amber diagnostic (300/300 missing, 120/130 corrupt), D41 refused with a red flash.
5. **D43 may calibrate from `AwaitingCalibration`** — necessary, or a fresh board can never be
   calibrated. Flagged as a deliberate extension of "Idle or Paused only".
6. **No boot sweep.** Boot loads and validates EEPROM; the sweep runs only on D43 (or bench `k`).
7. **EEPROM:** journal disabled (code kept); calibration owns two 64-byte slots at 0 and 64,
   magic/version/flags/sequence/CRC, magic written last, read-back verified.
8. **Write failure:** install the measurement in RAM first; on write/read-back failure run the
   session normally, show an amber cue, warn on serial, recalibrate next boot.
9. **Serial behaviour unchanged.** `s` stays a one-tick bench brake (documented; D41 is the real
   stop). `k` stays a mid-run bench sweep but now preserves the previous calibration when its
   sweep is degenerate. `g`/`j` unchanged. **No new serial keys.**
10. **Journal removal must not corrupt the ring.** `logInitIfNeeded()` + self-healing `logPush`
    and guarded `logAt`; `logHold` deleted; `x`/`z` survive.
11. **Build hardening:** `-Wswitch-enum -Werror` in `test/run_tests.sh`; `ledRgbFor()` moves the
    pixel→RGB decision into `LedDisplay.h` so the sketch has no enum switch; a test walks every
    `LedColor`. Amber can no longer render as a stale/black frame.
12. **Validation:** per-sensor `min < max` and span floor, enforced on encode *and* decode; an
    underived flank loads `defaultGreenThresholds()` before returning.
13. **Resets are pure and tested:** `entryActions(from, to)` owns brake/PID-reseed/marker-blank/
    settle/turn/expiry decisions. No event is posted from `onEnter()`.
14. **Enum numbering is append-only** (`Idle=6, AwaitingCalibration=7, Paused=8`) so stale log
    records and the `x` legend stay readable.
15. **Honest calibration window:** success ≈ 10.9 s, failure ≈ 12.9 s, all named; D41/D43 inert
    throughout; serial not polled and bytes processed afterwards.
16. **`Calibrate` is deadline-driven from the state switch**, not a nested blocking loop.
    Residual: SoftWire has no timeout — tagged UNVERIFIED, reset-only recovery.

## Rejected Alternatives

- Turn-remainder resume (`fullTurnMs − pivotElapsedMs`) — deleted by decision 1.
- Resume-target slot in the state value — deleted by decision 1.
- 25 ms instant-press start — replaced by 500 ms hold (accidental-brush risk).
- Serial `s` promoted to a real pause — rejected: blast radius.
- Serial `k` gated to Idle/Paused — rejected: blast radius.
- New diagnostic key `b` — rejected: no new keys.
- Single-slot EEPROM blob — replaced by two alternating slots (torn-write safety).
- Shrinking `JOURNAL_SLOTS` — replaced by disabling the journal entirely.
- Closed-loop fine-hunt resume — rejected: measured failure on the mat.

## Unresolved Objections (non-critical, owned)

- `CAL_MIN_SENSOR_SPAN = 50` is unevidenced; bench-measure and set.
- Button electrical convention `INPUT_PULLUP`/active-LOW is unverified; boot banner + checklist.
- SoftWire wedge during a sweep; no timeout; reset-only, UNVERIFIED.
- Pause mid-pivot leaves the robot at the reached heading; accepted consequence.
