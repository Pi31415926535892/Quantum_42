# Contract: RCJ Rescue Line 2026 — Team Quantum 42

## Objective

Build Quantum 42's robot from a broken PID line-follower harness into an autonomous,
rules-compliant RCJ Rescue Line 2026 competitor that completes the **full mission** — line
tracing through gaps, green-marker intersections, dead ends, ramps, seesaws, and obstacles to
the red goal tape (5 s stop = exit bonus), then entering the evacuation zone, locating the
three off-center-CoM victims, classifying live (silver + conductive) vs dead (black +
non-conductive), ignoring fakes, depositing them at the correct red/green triangles, and
exiting to finish — **all within the 8-minute game clock, on a single-button LoP restart,
with no pre-mapping**. Delivery is gated to a regional qualifier **one month out**; the RCJ
2026 World Championship (Incheon, Jul 1–7) is a stretch target.

Basis: RCJ Rescue Line 2026 official rules (final, 2026-03-29). Config-driven behavior is
mandatory because an updated rules version is expected later.

## Architectural Decisions

1. **Two-processor split (Mega real-time base + Nicla Vision perception)** — matches every serious analogue (Airborne RPi5+Pico); isolates the real-time 8-minute mission from vision framing. *Don-mandated.*
2. **UART Serial1 (D18/D19) + BSS138, not shared I2C** — the Wire bus is consumed by the marker mux; UART frees the bus and isolates failure domains. *Don D-1.*
3. **Weighted centroid PD as the line error source** — at locked 11.2 mm the centroid is the sensor's last resolution grace; coarse classes are qualifiers only. *Don D-2.*
4. **FSM as a transition table** — rule deltas and TC changes become row/entry edits, not rewrites.
5. **LoP = bounded boot + 360° ToF radar re-localization + hybrid bookkeeping** — deterministic, but re-orientation rides arena geometry rather than trusting stored navigation.
6. **Kinematics/mechanism isolated behind a stable interface** — the mission value never depends on a mechanical design that isn't done yet; the Q−14 gate decides enable/disable.
7. **Calibration-first posture** — improvised-only practice field + 11.2 mm ride height + variable arena lighting make the venue sweep the source of sensory truth; everything else carries last-good persisted state.
8. **CONFIG / CALIBRATION / TUNING split** — compile-time defaults, EEPROM arena samples, and runtime tuning are distinct layers so both rule drift and the Technical Challenge stay cheap.

## Grilling Conclusions

### Key Decisions

- **Target/λ gating:** qualifier-first; full mission required to advance; all P2 scope is gating.
- **Link:** Serial1 D18/D19 + BSS138 both directions; CRC8 + heartbeat + last-good cache; non-blocking ring; never block a state on a frame.
- **Line:** centroid PD; adaptive midpoints; 4-state classes as qualifiers; no cowling; ride height fixed 11.2 mm.
- **Obstacles:** Nicla ToF primary; 2-button front bumper as never-fail backstop; no HC-SR04.
- **Terrain:** seesaw = verify on mock, then gyro-guided slow straight (no turns); ramp = QTR guidance kept active (turns allowed).
- **LoP:** bounded boot (5 s READY timeout → degrade), 360° ToF radar sweep re-orientation, hybrid bookkeeping (victims/deposits persist; nav re-derived).
- **Mechanism:** isolated interface, contained-cup, Q−14 revisit gate, no-capture lane guaranteed.
- **Power:** Option A shared-rail via ferrite+LC; Option B auto-promotes only on P0 EMI fail.
- **Radios:** off by default for the match window.

### Rejected Alternatives

- **I2C as the host link** — bus contention with the marker mux; jitter on the vision channel.
- **HC-SR04 as obstacle fallback** — superseded by the bumper plate per the Don.
- **Light cowling on the QTR-8A** — rejected; centroid + adaptive midpoints win on raw contrast.
- **Coarse 4-state classes as the line control signal** — throws away the only resolution grace at 11.2 mm.
- **Full deterministic cold-restore / fresh-rebase LoP bookkeeping** — superseded by the hybrid + radar-sweep scheme.
- **Simulation-first twin** — rejected at the Sit-Down approach gate (Field-Driven chosen).
- **SD card on the deck** — defaulted off; EEPROM accounts suffice.

### Commandments

- CMD-01 **Hardware ground truth lives in HARDWARE.md first** — any pin/power/EMI change lands there before code claims it.
- CMD-02 **Calibration discipline** — no sensor constant acts on the robot without a venue-recorded calibration basis (the 10 s sweep, always).
- CMD-03 **Cross-validate** — no scored behavior rides a single sensor.
- CMD-04 **Non-blocking is universal** — FSM, link, mux churn, mechanism; nothing waits on a periphery unguarded.

### Negative Constraints

- NC-01 NEVER use a single-threshold boolean to gate a mission decision without a two-sided (black/white, present/absent) calibration basis and a logged diagnostic at calibration time.
- NC-02 NEVER ship a magic number in behavior code; every threshold/speed/score constant lives in CONFIG/CALIBRATION/TUNING.
- NC-03 NEVER `delay()` block in any mission FSM state, on the link path, or in mux channel handling.
- NC-04 NEVER make vision the sole classifier for victims (physical probes are mandatory).
